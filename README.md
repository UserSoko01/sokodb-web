# SokoDB Web

Sitio web corporativo para SokoDB, desarrollado con Next.js, TypeScript, Tailwind CSS y SMTP para formulario de contacto.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- Nodemailer
- Zod

## Rutas

- /
- /servicios
- /nosotros
- /contacto
- /aviso-de-privacidad

## Variables de entorno

Ver `.env.example`.

## Desarrollo local

```bash
npm install
npm run dev
